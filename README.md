# 아침 루틴 미션

아이 아침 루틴을 시간 안에 끝낼 수 있도록 만든 단일 HTML 대시보드입니다.

- **바로 열기:** https://gowooni85-ctrl.github.io/morning-routine/
- 아이패드/아이폰 사파이에서 열고 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.
- 등원 출발 목표 시간(기본 08:00)까지 남은 시간이 크게 표시되고, 남은 할 일 시간과 비교해 여유/촉박을 알려줍니다.
- `👩 엄마 설정`에서 목표 시간, 할 일 목록·시간을 바꿀 수 있습니다.
- 진행 상황은 그 기기의 브라우저(localStorage)에만 저장됩니다. 서버로 아무것도 보내지 않습니다.

`index.html` 하나로 동작하며 외부 CDN·이미지·폰트 파일이 없습니다.
