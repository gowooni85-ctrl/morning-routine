# 아침 루틴 미션

아이 아침 루틴을 시간 안에 끝낼 수 있도록 만든 단일 HTML 대시보드입니다.

- **바로 열기:** https://gowooni85-ctrl.github.io/morning-routine/
- 아이패드/아이폰 사파리에서 열고 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.
- 오늘이 토·일이면 **🌈 주말 모드**(가방 싸기 빼고 7단계 · 목표 10:00), 월~금이면 **🎒 평일 모드**(8단계 · 목표 08:00)로 저절로 열립니다.
- 머리말의 모드 버튼(🎒 평일 / 🌈 주말)을 누르면 그날 하루만 모드를 바꿔 볼 수 있어요.
- 목표 시간까지 남은 시간이 크게 표시되고, 남은 할 일 시간과 비교해 여유/촉박을 알려줍니다.
- 할 일 타이머가 **00:00**이 되면 밝은 종소리 알림음이 울리고, 그 할 일은 자동으로 완료되며 **다음 할 일 타이머가 저절로 이어서 시작**됩니다. (`👩 엄마 설정 → 🔔 소리 테스트`로 미리 확인)
- 맨 마지막 **🎲 놀기**는 시간을 정하지 않아도 목표 시간까지 남는 시간이 저절로 계산됩니다. (다른 할 일을 일찍 끝낼수록 늘어나요)
- `👩 엄마 설정`에서 모드별 목표 시간과 할 일 목록·시간을 따로 바꿀 수 있습니다.
- 진행 상황은 그 기기의 브라우저(localStorage)에만 저장됩니다. 서버로 아무것도 보내지 않습니다.

기본 시간: 약 5분 · 샤워/옷/로션/머리 15분 · 아침상+식사 25분 · 식후 약 5분 · 이 닦기 5분 · (평일) 가방 싸기 5분 · 리딩게이트 평일 15분 / 주말 25분.

`index.html` 하나로 동작하며 외부 CDN·이미지·폰트 파일이 없습니다.
